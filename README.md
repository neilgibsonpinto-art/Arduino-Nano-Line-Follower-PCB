# Arduino Nano Line Follower Robot

A high-performance autonomous **line follower robot** built around the **Arduino Nano** with a **custom-designed 8-channel IR sensor PCB** for accurate and reliable line detection. The robot uses differential drive control and a compact custom PCB, making it suitable for robotics competitions, embedded systems projects, and educational applications.

---

## 🚀 Features

- Custom-designed 8-channel IR sensor PCB
- Arduino Nano controller
- High-accuracy line detection
- Differential drive motor control
- Compact and lightweight robot
- Modular hardware design
- Easy programming using Arduino IDE
- Competition-ready architecture

---

## 🛠 Hardware

| Component | Description |
|-----------|-------------|
| Microcontroller | Arduino Nano |
| Line Sensors | 8 × IR Reflective Sensors |
| Motor Driver | TB6612FNG |
| Motors | N20 DC Gear Motors |
| Battery | Li-ion/LiPo |
| PCB | Custom Designed in KiCad |
